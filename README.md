# FructCity — интернет-магазин продуктов с доставкой

> Коммерческий проект. Код закрыт по договорённости с заказчиком, здесь — описание решения.
> Сайт: https://fructcity.ru

**Роль:** единственный разработчик — backend, фронтенд, деплой. Требования согласовывал с заказчиком.

<!-- Скриншоты: витрина, корзина, админ-панель (согласовать с заказчиком) -->

## Что умеет
- Витрина, корзина, оформление заказа, промокоды, предзаказы.
- Админ-панель: каталог, заказы, закупки, выгрузки.
- **Весовой товар:** точный вес известен только при сборке, итог заказа пересчитывается после взвешивания.
- **Интеграция со СБИС:** импорт каталога (CommerceML и Excel), автоимпорт фото по FTP, наличие из выгрузки.
- SSR-страницы для SEO, Telegram-бот для уведомлений.

## Стек
Python, FastAPI, SQLAlchemy, PostgreSQL 16, Alembic (10 миграций), Docker Compose, Caddy (HTTPS), JavaScript без сборки.

## Архитектура
```
браузер ──HTTP + cookie──► транспорт (роутеры, статика, SSR, заголовки безопасности)
                          ► контекст запроса (сессия, CSRF, лимиты, транзакция)
                          ► домен (расчёт заказа, правила каталога — чистый Python)
                          ► хранилище (PostgreSQL через SQLAlchemy)
```
Расчёт денег на витрине и на сервере — один и тот же код, чтобы цена в корзине никогда не расходилась с итогом.
